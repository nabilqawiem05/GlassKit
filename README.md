# GlassKit

Jam lock screen depth effect + pil gaya Dynamic Island untuk Pixel. Tanpa root.

## Build guna GitHub (dari phone)
1. Buat repo baru di github.com (boleh Private).
2. Add file > Create new file. Nama: `.github/workflows/build.yml`. Tampal isi fail build.yml. Commit.
3. Add file > Upload files. Upload `GlassKit.zip`. Commit.
4. Tab Actions > tunggu build hijau (lebih kurang 5 minit) > buka build > Artifacts > GlassKit-apk.
5. Unzip, install `app-debug.apk`.

## Lepas install
- Jalan arahan dalam app (butang "Salin arahan aShell") dalam aShell untuk buka kunci Accessibility & Notification access.
- Jam: Pilih wallpaper > Potong subjek > laras > Set sebagai wallpaper (pilih Lock screen atau Home & lock).
